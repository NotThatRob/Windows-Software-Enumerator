# AI Usage Policy

## Purpose
This repository encourages the use of AI-assisted development tools to improve productivity, accelerate learning, and reduce repetitive work. At the same time, all contributions must meet the same standards of quality, security, and correctness expected from fully human-authored code.

AI is a tool—not a source of truth.

---

## Guiding Principles

- **AI as an Assistant, Not a Decision-Maker**  
  AI tools may suggest code, documentation, tests, or designs, but they do not replace human judgment.

- **Human Accountability**  
  Responsibility for all code rests entirely with the human contributor and reviewers—regardless of how the code was generated.

- **Quality Over Convenience**  
  Code generated by AI must meet the same standards for readability, maintainability, performance, and security as manually written code.

- **Transparency**  
  Contributors should be open about meaningful use of AI tools, especially for non-trivial contributions.

---

## Acceptable Use

AI tools (e.g., code assistants, chat-based tools, or generators) may be used for:

- Generating boilerplate code
- Drafting documentation
- Assisting with debugging or refactoring
- Writing test cases
- Exploring alternative implementations

---

## Required Human Review

Before submitting or approving any contribution:

- **Understand the Code**  
  The contributor must fully understand any AI-generated code they include.

- **Verify Correctness**  
  Validate logic, edge cases, and expected behavior.

- **Check Security & Compliance**  
  Ensure no sensitive data leakage, insecure patterns, or licensing issues.

- **Ensure Consistency**  
  Align with project conventions, architecture, and style guidelines.

- **Test Thoroughly**  
  Do not assume AI-generated code is correct—tests are required where appropriate.

- **Review Depth Matters**  
  Review must go beyond surface-level inspection—contributors should be confident they could explain and defend the code they submit.

---

## Prohibited Practices

- Submitting AI-generated code without review or understanding
- Blindly copying and pasting AI outputs into the codebase
- Using AI tools to generate code that violates licensing or intellectual property rules
- Relying on AI to make architectural or security decisions without human validation

---

## Disclosure Guidelines (Optional but Encouraged)

For significant AI-assisted contributions, consider noting it in the pull request:

> “This change was developed with assistance from an AI coding tool and has been fully reviewed and validated.”

---

## Enforcement

Maintainers reserve the right to:

- Request additional review or revisions for AI-assisted contributions
- Reject changes that do not meet quality or review standards
- Update this policy as tools and best practices evolve

---

## Final Note

AI can significantly enhance development workflows, but it does not replace critical thinking. Treat AI-generated output with the same skepticism and care as any external contribution.
